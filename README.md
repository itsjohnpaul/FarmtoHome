# EcommerceVeg

A vegetable ecommerce platform with React frontend and Node.js backend.

## Setup

### Prerequisites
- Node.js
- MongoDB (for backend)

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
```bash
cd backend
npm install
npm start
```

Make sure MongoDB is running on localhost:27017.

## API Endpoints
- GET /api/products - Get all products
- GET /api/products/:id - Get product by ID
